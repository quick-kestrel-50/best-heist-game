A one-screen midnight museum stealth game. You are the Velvet Fox, a phantom thief in a teal hood: cross the gallery under the guards' amber vision cones and the cameras' sweeping red beams, toss decoy coins to pull patrols off their routes, slip the laser gate, lift the Moonlight Sapphire — leaving only your white calling card on the empty plinth — and reach the door before the shared ALARM meter fills. Static files, no network, keyboard and mouse, written in vanilla JavaScript and canvas.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. WASD / arrows move, Shift sprints, click tosses a decoy coin, E interacts, R restarts.
